## 📌 Contexte du projet

Dans le cadre de ma formation **Engineer Intelligence Artificielle (AI)**, ce projet correspond au **Projet-5 : Déployez un modèle de Machine Learning**.  

Je me place dans la peau d’un **freelance spécialisé en machine learning**, mandaté par **Futurisys**, une entreprise innovante souhaitant rendre ses modèles de ML **opérationnels, sécurisés et accessibles via une API performante**.

Le directeur technique de Futurisys, **Aurélien**, formule une demande claire :  
👉 **mettre en production un modèle de machine learning** (issu du Projet 4 – *Classifiez automatiquement des informations*) en respectant les **meilleures pratiques de l’ingénierie logicielle et MLOps**.

L’objectif final est de livrer un **Proof of Concept (POC) fonctionnel**, professionnel et industrialisable.

---

## 🎯 Objectifs

- Exposer un modèle de Machine Learning via une **API REST** performante
- Garantir la **fiabilité et la robustesse** du code grâce aux tests
- Mettre en place un **workflow CI/CD complet**
- Gérer les données et les prédictions via une **base PostgreSQL**
- Fournir une **documentation claire et exploitable**

---

## 🧱 Architecture & Livrables

Le projet comprend l’ensemble des livrables attendus pour une mise en production ML moderne :

### 📁 Dépôt Git structuré
- Code source complet (API, ML, scripts, tests)
- Gestion des dépendances (`requirements.txt` / `pyproject.toml`)
- Historique de commits clair (branches, tags, versioning)
- Documentation complète via ce **README.md**

### ⚡ API Machine Learning
- Développée avec **FastAPI**
- Exposition du modèle ML via endpoints REST
- Documentation interactive **Swagger / OpenAPI**
- Gestion des schémas de données et exemples d’appels

👉 **Swagger UI**  
🔗 [https://remdev-ai-futurisys-api.hf.space/docs](https://remdev-ai-futurisys-api.hf.space/docs)

---

### 🧪 Tests unitaires & fonctionnels
- Tests écrits avec **Pytest**
- Couverture des cas critiques et scénarios d’erreur
- Rapport de couverture via **pytest-cov**
- Intégration automatique dans la CI

---

### 🗄️ Base de données PostgreSQL
- Script de création de la base et des tables
- Modèles ORM / documentation du schéma
- Données d’exemple (CSV / SQL)
- Scripts d’interaction avec le modèle ML

---

### 🔁 CI/CD & Sécurité
- Pipeline **GitHub Actions**
- Environnements : `dev`, `test`, `prod`
- Exécution automatique des tests
- Gestion sécurisée des secrets (GitHub Secrets)

---

## 🗺️ Déroulé du projet

Le projet est structuré autour des étapes suivantes :

1. **Mise en place du versioning et de la collaboration Git**
2. **Configuration de la CI/CD**
3. **Développement de l’API FastAPI**
4. **Insertion et gestion du dataset via PostgreSQL**
5. **Développement des tests unitaires et fonctionnels**
6. **Documentation du modèle de Machine Learning**
